Що залишається на вашому пристрої

Редагування зображень, скорочення палітри, калібрування філаментів, планування шарів, 3D-перегляд і експорт моделей працюють локально у браузері або настільному застосунку. Облікового запису Kromacut чи хмарного сховища проєктів немає.

Відкриття зображення дозволяє застосунку прочитати файл локально. Експортовані моделі, палітри та профілі філаментів зберігаються як файли на вашому пристрої. Kromacut не надсилає ці файли кудись автоматично.

Збережені налаштування, файли cookie й очищення даних

Застосунок використовує локальне сховище для налаштувань, тем, палітр, профілів філаментів та історії калібрування. Застосунок не встановлює строку дії цих збережених параметрів; вони залишаються до видалення або очищення сховища браузером чи пристроєм.

Kromacut не встановлює рекламних чи аналітичних cookie. Збережені параметри використовують локальне сховище браузера, окреме від cookie, яке не надсилається автоматично із запитами до сайту.

Перед очищенням даних сайту чи застосунку експортуйте профілі й палітри, які хочете зберегти. Очищення сховища браузера може назавжди видалити історію калібрування. Файли, раніше експортовані на пристрій, не видаляються.

Хостинг сайту й з’єднання

Сайт розміщено на GitHub Pages. Під час відвідування служба хостингу отримує звичайні відомості про з’єднання й запит. GitHub зазначає, що Pages записує IP-адреси відвідувачів для безпеки, навіть якщо вони не ввійшли в GitHub.

Шрифти входять до Kromacut і надаються із сайту або настільної інсталяції. Відкриття застосунку не звертається до Google Fonts. Kromacut не містить реклами чи аналітичного SDK.

Надання сайту й публічної інформації про оновлення відповідає законному інтересу забезпечувати доступність і безпеку Kromacut (стаття 6(1)(f) GDPR). GitHub також самостійно визначає цілі безпеки й обробки даних сервісу, як пояснено в його заяві про конфіденційність.

Настільні оновлення й діагностика

Перевірка настільних оновлень запитує публічний файл version.json із kromacut.com. Автоматичні перевірки ввімкнені за замовчуванням, виконуються під час запуску й кожні чотири години, поки застосунок відкритий; їх можна вимкнути в налаштуваннях. Ручна перевірка залишається доступною.

Запит оновлення не містить ваших зображень, профілів, налаштувань або встановленої версії. Порівняння версій відбувається локально, але хостинг усе одно отримує звичайні відомості про з’єднання.

Необов’язковий діагностичний запис Auto-paint за замовчуванням вимкнений і створює локальні файли. Вони можуть містити відомості про виконання, філаменти, калібрування та кольори палітри, але не вихідне зображення. Файли залишаються на пристрої до видалення. Перегляньте їх перед поширенням.

Коли ви надсилаєте електронного листа

Kromacut керується особисто. Оператор визначає використання та зберігання прямого листування з підтримки й конфіденційності. Якщо ви напишете на адресу нижче, оператор отримає у Gmail адресу відправника, зазначене вами ім’я, повідомлення й вкладення. Google також обробляє ці дані для надання та захисту своєї поштової служби.

Листування з підтримки використовується для відповіді вам, дослідження порушеної проблеми та необхідного подальшого супроводу. Правова підстава — законний інтерес надавати запитану підтримку й підтримувати Kromacut (стаття 6(1)(f) GDPR), збалансований із вашими правами на захист даних. Обробка відповідних запитів щодо конфіденційності спирається на правовий обов’язок поважати ці права (стаття 6(1)(c)).

Звертатися до оператора необов’язково для користування застосунком. Без адреси для відповіді чи достатніх відомостей про проблему відповісти може бути неможливо. Надсилайте лише доречні дані; уникайте чутливих персональних даних або відомостей про інших осіб, якщо вони не потрібні.

Як довго зберігається листування

Листування Kromacut переглядається кожні шість місяців. Повідомлення й вкладення видаляються, коли більше не потрібні для невирішеної проблеми, необхідного подальшого супроводу або з правових причин. Це ручний перегляд, а не автоматичне закінчення строку кожного листа через шість місяців.

Якщо записи потрібні для виконання правового обов’язку або встановлення, здійснення чи захисту правової вимоги, зберігаються лише необхідні дані протягом відповідного законного строку або доки цього потребує вимога. Мінімальні записи запитів щодо конфіденційності та відповідей можуть зберігатися як підтвердження їх розгляду; потреба в них також переглядається.

Це правило поштової скриньки не визначає незалежні строки зберігання GitHub чи Google. Їхні повідомлення про конфіденційність описують зберігання відповідно до цілей сервісу й правових потреб. Видалення зі скриньки не гарантує негайного вилучення з резервних копій чи журналів безпеки постачальників.

Постачальники й міжнародна обробка

GitHub надає хостинг сайту, Google — контактну поштову скриньку. Ці постачальники та їхні підрядники обробляють інформацію, пов’язану із цими послугами. Вони також є контролерами для самостійно визначених цілей, зокрема безпеки сервісу та дотримання законодавства. Доречне листування може бути передано раднику чи органу влади, якщо це необхідно для правового питання або виконання закону.

GitHub і Google описують обробку за межами Європейської економічної зони, зокрема у США. Опубліковані гарантії включають застосовні рішення про належність захисту та стандартні договірні положення; обидві компанії описують участь своїх американських юридичних осіб у Рамковій угоді ЄС–США про захист даних. Посилання нижче пояснюють відповідні домовленості постачальників і способи отримання інформації. Питання щодо конфіденційності можна також надіслати за контактом нижче. Ці домовленості стосуються хостингу й листування, а не автоматичного завантаження ваших зображень.

Посилання спільноти й підтримка на Patreon

Посилання на спільноту, підтримку й випуски відкривають зовнішні сайти. Опублікована вами інформація, наприклад публічна заявка чи повідомлення спільноти, обробляється за правилами конфіденційності відповідного сервісу й може бути видимою іншим.

Кнопка підтримки відкриває Patreon із власними правилами конфіденційності й платежів. Якщо ви станете учасником, Patreon може надати автору дані прихильника: ім’я профілю, електронну адресу, рівень членства, статус і суму. Це окремо від локальної обробки зображень у Kromacut. Creator Privacy Promise Patreon описує ролі й обов’язки щодо даних членства, які використовуються для відповідних послуг.

Для запитів щодо конфіденційності облікового запису чи платежів Patreon використовуйте канали Patreon. Якщо питання стосується інформації, отриманої автором, можна також скористатися контактом нижче.

Ваші права на захист даних

Якщо застосовується GDPR, ви можете вимагати доступу до персональних даних, виправлення неточностей, видалення або обмеження обробки за умовами цих прав. Ви можете заперечити проти обробки на основі законних інтересів із причин, пов’язаних із вашою ситуацією.

Переносність застосовується до автоматизованої обробки на основі згоди чи договору. Якщо підставою є згода, її можна відкликати без впливу на законність попередньої обробки. Kromacut не використовує персональні дані для автоматизованих рішень щодо вас із правовими або подібними значними наслідками.

Надішліть запит на адресу нижче. Опишіть потребу та доречне листування; спеціальна форма не потрібна. Запити зазвичай безкоштовні. Додаткові ідентифікаційні дані запитуються лише за обґрунтованої потреби підтвердити належність даних вам; не надсилайте посвідчень особи без запиту.

Ви отримаєте відповідь без невиправданої затримки та протягом одного місяця. Якщо складність або кількість запитів потребує продовження, протягом першого місяця вам повідомлять причини; строк може бути продовжено ще до двох місяців. Якщо запит неможливо виконати, відповідь пояснить причини та доступні способи скарги й судового захисту.

Оператор не може віддалено переглядати чи видаляти зображення, налаштування або експортовані файли, що зберігаються лише на вашому пристрої. Скористайтеся описаними вище локальними засобами. Для даних під незалежним контролем постачальника його канали конфіденційності доступні через пов’язані повідомлення.

Питання щодо конфіденційності

Для питання чи запиту щодо конфіденційності покажіть публічну контактну адресу нижче. Показ або копіювання адреси нічого не надсилає. Надсилання листа передає повідомлення й вкладення оператору та залученим поштовим службам, зокрема Gmail.
