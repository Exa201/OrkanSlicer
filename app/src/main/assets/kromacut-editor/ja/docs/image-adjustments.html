画像調整

調整は減色前の目標画像を変えます。フィラメントの校正、遮蔽距離の変更、表示色が実際に印刷可能であることの保証ではありません。

スライダーを動かすと効果をプレビューできます。操作が終わると表示が更新されます。初期値はすべてゼロです。個別のリセット矢印は1つのスライダーを、パネルのリセットは全スライダーを戻します。

色調と色の操作

これらは変化方向の模式例であり、校正済みの印刷予測ではありません。効果は元画像と他の有効な調整に依存します。

色調

スライダー範囲マイナス値プラス値印刷準備への影響
露出−3〜+3段、刻み0.01RGB値を暗くします。明るくします。+1でチャンネル値が倍になり、上限で切り詰めます。目標の色調全体を動かします。描画済み画像の調整なので、失われたRAW情報は復元できません。
コントラスト−100%〜+100%色調を中間の灰色に近づけます。−100%では他の調整前に中間灰色になります。中間灰色から離し、黒/白で切り詰めます。大きな領域を分離できますが、微妙な暗部や明部を平坦にする場合があります。
ハイライト−100%〜+100%明るい領域を暗くします。明るい領域を明るくします。パレット候補の明るい色調を変えます。存在しない細部は復元できません。
シャドウ−100%〜+100%暗部を暗くします。暗部を明るくします。減色前に既存の暗部の差を見えやすくできます。
白レベル−100%〜+100%最も明るい領域を暗くします。最も明るい領域を明るくします。白に近い目標色を分離または統合します。ホワイトバランス設定ではありません。
黒レベル−100%〜+100%最も暗い領域を暗くします。最も暗い領域を明るくします。黒に近い目標色を変えます。値を倍率で変えるため、純黒は黒のままです。

ハイライト/シャドウは白レベル/黒レベルより広い範囲を対象とします。範囲は重なり、とても暗いピクセルは黒レベルとシャドウの両方に反応します。色調範囲は露出、コントラスト、色温度/色かぶり補正、HSL調整の後で評価するため、操作は相互に影響します。

色と局所的な細部

スライダー範囲マイナス値プラス値印刷準備への影響
彩度−100%〜+100%鮮やかさを減らし、−100%で無彩色にします。鮮やかさを増やします。画像の色差を変えますが、実物フィラメントの色域は変えません。
自然な彩度−100%〜+100%比較的低彩度の色をより強く下げます。比較的低彩度の色をより強く上げます。彩度より一律でない処理ですが、肌色を認識するものではありません。純粋な灰色は灰色のままです。
色相−180°〜+180°色相を一方向に回します。反対方向に回します。画像全体を変色します。1つの完全一致色には色見本編集を使います。
色温度−100〜+100寒色寄り：赤を減らし青を増やします。暖色寄り：赤を増やし青を減らします。概算の色かぶり調整であり、ケルビンではありません。
色かぶり補正−100〜+100緑を加えます。赤/青を増やし緑を減らしてマゼンタを加えます。色かぶりを補正または追加します。実測のカメラプロファイルではありません。
明瞭度−100〜+100局所コントラストを弱めます。局所コントラストと輪郭を強調します。減色が必要な輪郭色やハローを作る場合があります。細部の復元や細線の拡幅はしません。

露出と色相以外は整数刻みです。アルファは変わりません。減色のアルファ処理は異なり、半透明ピクセルを完全に不透明にします。

プレビューと適用の違い

適用は現在の見え方を元の作業画像に反映し、スライダーをゼロに戻し、画像履歴に1段階を追加します。減色、モデル作成、印刷設定の変更は行いません。

この違いは重要です。

  • 減色、画像のサイズ変更、画像のダウンロード、3D生成は元の作業画像を使い、未適用のプレビュー調整は使いません。
  • 画像の色は元のピクセルを表すため、ライブ調整に合わせて色見本は変わりません。
  • 修正ツールは元画像を編集し、有効な調整がその上に再びかかります。
  • ディザ除去は調整後の画像を読み取ります。処理済み結果に調整が重ならないよう先に適用してください。

確実な順序は調整をプレビュー → 調整を適用 → 減色 → 確認/クリーンアップ → 3D作成です。可能なら切り抜きとサイズ変更はその前に行います。

リセットと元に戻すは別

リセットはライブ調整を除きますが、適用済みの画像編集は取り消しません。適用後にスライダーがゼロなのは正常です。以前の効果はすでに画像に含まれています。以前の画像に戻すには元に戻すを使います。

適用を繰り返すと編集済み画像をさらに編集するため、白飛び・黒つぶれや色調の細部の損失が蓄積する場合があります。別案を比較するときは先に元に戻してください。
