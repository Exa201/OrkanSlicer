設定と操作

このページでは、アプリ全体に影響する操作や見落としやすい操作をまとめます。

ヘッダーの操作

操作動作
Kromacutロゴドキュメントを開いているときはアプリに戻り、それ以外ではホームページを開きます。
設定言語、テーマ、リソース、更新の操作を含む設定ダイアログを開きます。

テーマはシステム、ダーク、ライトから選べます。システムはOSまたはブラウザーの配色設定に従い、その設定が変わると更新されます。テーマの選択は次回以降も保存されます。

言語の選択は、インターフェース、ドキュメント、図、公開ページを変更します。システムの言語で対応するブラウザーまたはOSの言語に従うか、英語、フランス語、ドイツ語、イタリア語、ルーマニア語、スペイン語、日本語、簡体字中国語、ヒンディー語、ポルトガル語（ポルトガル）、ウクライナ語、ベンガル語を選べます。選択はローカルに保存され、絵柄、フィラメントプロファイル、印刷設定、生成形状は変わりません。翻訳リソースとフォントはデスクトップアプリに同梱され、オンライン翻訳サービスに作品が送信されることはありません。

公開ページにも言語選択があります。翻訳ドキュメントは/ro/docs/overviewのような言語接頭辞付きの共有リンクを使います。ページ名と節のアンカーは言語が変わっても安定しています。拡張子、モデルの数値データ、ユーザー入力名、コミュニティ作品の元の題名は翻訳されません。

設定ダイアログにはドキュメント、Discord、Reddit、GitHub、Patreonへのリンクと、現在のKromacutのバージョンが表示されます。 プライバシーとローカルデータと利用規約もここから利用でき、選択した言語でブラウザーに開きます。

作業領域のモード

2Dと3Dボタンで画像準備とモデル生成を切り替えます。

操作パネルとプレビューの間の縦の仕切りはドラッグできます。詳細設定では左パネルを広げ、画像やモデルの確認ではプレビューを広げてください。

ドキュメントは共有可能な/docs/...リンクを使います。リンクを開くと対応するガイドに直接移動します。

小さな画面では、目次を開いてガイドを選ぶか、このページを開いて節に移動します。どちらも選択後に閉じて読書領域を確保します。図はクリックするかリンクにフォーカスしてEnterを押すと原寸大で開けます。

サイドバーの多くの節は見出しで折りたためます。折りたたむのは操作欄だけで、効果ではありません。有効な調整、印刷設定、最適化オプションは引き続き適用されます。折りたたみ時の要約や状態点で有効な変更を把握できます。開閉状態は記憶されます。展開してもリセットされません。

元に戻す / やり直すは2Dと3Dで画像編集履歴を共有します。フィラメント編集、校正、層の高さ、最適化設定の取り消し履歴ではありません。利用できる場合は各パネルのリセットを使い、画像状態を復元した後は再作成してください。

実験的な複数プレートモード

設定の複数プレートモードは未完成の作業方式です。設定を記憶し、プレビューアニメーションを再生できますが、現在は画像の分割、タイル作成、複数プレートへの配置、書き出し形状の変更は行いません。通常の印刷ではオフにしてください。大きすぎるモデルをベッドに収める方法としては使わないでください。

保存される印刷設定

Kromacutはピクセルサイズ（XY）、層の高さ、初層の高さ、実効線幅、滑らかなメッシュなどの印刷設定をブラウザーに記憶します。

実効線幅0.42 mmを含む既定値に戻すには、3D印刷設定のリセットボタンを使います。

記憶した設定は現在のブラウザー/サイトまたはデスクトップアプリ内だけのものです。作品のバックアップや完全な保存プロジェクトではなく、別のブラウザーやデスクトップアプリと共有されるとは限りません。アプリやブラウザーデータを消去する前に、重要なパレットとフィラメントプロファイルを書き出してください。プロファイルの読み込みで復元されるのはフィラメントと測定データであり、画像や作成済みメッシュではありません。

保存される自動ペイントの状態

自動ペイントの設定はセッションをまたいで保持されます。次の内容が含まれます。

  • フィラメント。
  • ペイントモード。
  • 最大高さと校正ウェッジの層の高さ。
  • 高度な色合わせ。
  • 色の分離の保持、一意一致のΔE上限、すべての色に一意一致を求めるかどうか。
  • 合計繰り返し上限（積層全体で共有するフィラメントの追加使用回数）。
  • 遷移の細部と高さディザ。
  • 幅警告、孤立点除去、高さディザに使う実効線幅（3D印刷設定で編集）と、孤立した色の点を除外の設定。この除去設定はすべての幅警告を消すものではなく、高さディザも制御しません。
  • フラット印刷と、表向き・透明層なしの設定。
  • 最適化アルゴリズムとシード。
  • 領域の優先度。

プロファイルはこの記憶状態とは別です。名前付きのフィラメント構成を読み込み、取り込み、書き出したいときに使います。

パレットファイル

独自パレットは2D減色用です。パレットファイルには.kpalを使います。

パレット形式バージョン2では、disabledColors（パレットに残すが減色から除外する色）とcolorNames（色ごとの任意の表示名）の2つの任意項目を追加しています。どちらも書き出しと読み込みで保持されます。バージョン1は変更せず読み込め、すべて有効で名前なしになります。古いKromacutでv2を開くと、すべての色が有効として扱われます。

減色した画像を既知のフィラメント構成や固定の色セットに合わせたいときに独自パレットを使います。

フィラメントプロファイルファイル

自動ペイントのフィラメントプロファイルは、保存、読み込み、取り込み、書き出しができる名前付きフィラメント構成です。.kfilを使い、色、名前、遮蔽距離、校正データ、保存した配色見本の記録と評価、利用可能な場合は上限付きの積層校正マトリクス計画と測定色を保存します。古い.kappプロファイルも取り込めます。古いバージョンの未校正値は従来のTD尺度で保存されており、読み込みまたは取り込み時に自動変換（×0.1）されます。

取り込むには自動ペイントのプロファイルツールバーのアップロードアイコンを使います。同じIDの古いファイルに見え方データがない場合、新しい校正データを消さず、名前を変えた別コピーとして取り込みます。保存に失敗した場合は既存リストを変えずエラーを表示します。現在の構成の書き出しにはダウンロードアイコンを使います。既定拡張子は.kfilです。読み込み中のプロファイルに未保存のフィラメント編集がある場合は、新しい「未保存の編集」プロファイルとして書き出し、古いフィラメント識別子に結び付いた見え方データは含めません。

重複の処理

取り込み時、Kromacutは各プロファイルを保存済みのものと照合します。

  • 同じID：通常は既存プロファイルを上書きします。ただし使用可能なデータのないファイルで保存済みの見え方データを置き換える場合は、別コピーとして取り込みます。
  • 同じ内容、異なるID：フィラメントデータと見え方データの両方が既存プロファイルと一致する場合だけ省略します。
  • 同じ名前、異なる内容：名前に数値の接尾辞を付けて取り込みます（例：My Spools (2)）。

取り込みごとに、取り込み、上書き、省略、改名の件数の短い要約を表示します。

HueForgeから取り込む

HueForgeのスプールライブラリ書き出し（.csvまたは.tsv）は直接取り込めます。HueForgeのExport SpoolsでCSVを保存し、自動ペイントのフィラメントプロファイルツールバーのアップロードアイコンでファイルを選びます。区切り文字（コンマまたはタブ）はヘッダー行から自動判定します。各スプールは<Brand>-<Color Name>-<Hex>形式のフィラメント名になります。例：Inland Basic-Light Brown-#BF9C81。HueForgeのUUIDはフィラメントIDとして保持するため、同じライブラリを再取り込みしても重複しません。HueForgeのTD値は従来の背面照明/リトファン用TD入力として扱い、取り込み時に前面照明の遮蔽距離へ変換します。

デスクトップの更新通知

デスクトップアプリでは、新しいバージョンがあるとKromacutが更新通知を表示できます。通知からダウンロードページを開くか、通知を閉じられます。

手動で更新を確認するには設定を開きます。デスクトップ設定の起動時に確認は、アプリ起動時に更新を調べるかどうかを制御します。既定で有効ですが、オフでも手動確認は使えます。

Linuxでは、更新情報が埋め込まれたAppImageを、AppImageUpdateなどの対応ツールで更新できます。これらのツールは、リリースの.AppImage.zsyncファイルを使って変更部分をダウンロードします。更新情報のない古いAppImageを使用している場合は、最初の一度だけ対応版を手動でダウンロードする必要があります。.zsyncファイルはインストーラーではなく、Kromacutの更新通知が更新を自動インストールすることもありません。

デスクトップの自動ペイント診断

デスクトップアプリは新しい自動ペイント計算の構造化情報を記録できます。計算を開始する前に設定で自動ペイントの診断を記録を有効にします。すでに計算済みの結果を再実行したり、さかのぼって記録したりはしません。

計算ごとにKromacutの自動ペイント診断フォルダーへ別の.jsonlファイルを作ります。設定の横のフォルダーを開くで探してください。各行は完全なJSONイベントなので、計算が完了しなくても進捗、エラー、キャンセルを読めます。

完了した記録には、基本的な実行環境、現在のフィラメントと校正のスナップショット、作成・最適化設定、上限付きの進捗サンプル、見え方の当てはめ状態、段階的な繰り返し階層の判断、最終物理層、最終的な全印刷可能色候補、目標と候補のDelta E比較、予測信頼度、補間色や局所当てはめ色に寄与した測定が含まれます。記録するのは処理済みパレット色と重みであり、アップロードした元画像ではありません。それでも校正とプロファイルは機密性を持つ場合があるため、公開する前に記録を確認してください。

記録は調査用で、ファイルが大きくなる場合があります。通常の印刷で記録が不要なら無効のままにしてください。

デスクトップからファイルを開く

デスクトップ版では、.kfil と旧形式の .kapp がフィラメントプロファイルに、.kpal がパレットに関連付けられます。ファイルをダブルクリックすると、Kromacut にインポートして選択できます。アプリが起動済みの場合は既存のウィンドウで処理されます。通常の検証、移行、重複処理、キャリブレーション保持のルールが適用されます。

パレットエディター、キャリブレーションダイアログ、またはプロファイルの名前変更・新規保存フォームが開いている間、デスクトップから開いたファイルは待機します。編集中の作業を完了するかキャンセルすると、待機中のインポートが続行されます。それまでは、入力した名前と編集中のプロファイルは変更されません。

フィラメントの名前やHD欄を編集中、またはそのカラーピッカーやTDから変換のポップオーバーが開いている間も、インポートは待機します。入力欄からフォーカスを外すか、ピッカーまたはポップオーバーを閉じると、待機中のインポートが再開します。未保存のフィラメント編集を別のプロファイルで置き換える前には、引き続き確認が表示されます。

未保存のフィラメント編集を置き換える前に、Kromacut は 編集を保持 または プロファイルを開く を表示します。先に保存する場合は編集を保持してください。プロファイルを開くと未保存の編集は破棄されます。この方法で開くファイルは 32 MiB 未満である必要があります。一般的な JSON、画像、モデルは通常のインポート手順を使用します。

Linux のポータブル AppImage でファイルを関連付けるには、デスクトップへの統合が必要です。Kromacut が既定のアプリでない場合は、ファイルマネージャーの 別のアプリで開く を使用してください。
