概要

Kromacutは平面画像を、色の層を積み重ねた3Dプリントに変換します。中心となる考え方は単純です。画像の色が物理的な層になり、その順番と高さが印刷計画になります。

HueForge風の印刷、カラーリトファン風のレリーフ、フィラメント交換によって最終的な画像を作る積層展示作品を作りたいときにKromacutを使ってください。

主な作業の流れ

多くのプロジェクトは同じ手順で進みます。

  1. 画像を読み込む、または取り込む。
  2. 印刷可能なパレットになるまで減色する。
  3. 画像にノイズがある場合、孤立ピクセルをディザ除去またはクリーンアップする。
  4. 3Dモードに切り替え、手動または自動ペイントを選ぶ。
  5. STLまたは3MFファイルを作成して書き出し、印刷手順に従う。

2つの色付け方法

Kromacutの3Dモードには2つの印刷方式があります。

方式適した用途操作する項目
手動画像の各色を直接制御したい場合。色の順番、色ごとの厚み、印刷設定、交換。
自動ペイント物理的なフィラメント積層の計画をKromacutに任せたい場合。フィラメント色、遮蔽距離、最大高さ、最適化オプション。

手動モードは画像の色パネルに表示された色から始まります。自動ペイントは実際のフィラメントとその遮蔽距離（HD）から始まり、画像に合わせた印刷可能な層を生成します。

アプリに表示されるもの

2Dで絵柄を準備し、3Dで物理的な層を計画します。以下のガイドもこの区分に沿っています。

図解ガイド

やりたい作業から始めてください。各ガイドでは操作、相互作用、実物の印刷への影響を説明します。図は模式例で、校正済みの色予測ではありません。図をクリックするかキーボードで選択すると原寸大で開きます。

作業領域の構成

作業領域には主に3つの部分があります。

  • ヘッダーにはドキュメント、テーマ操作、コミュニティリンクがあります。
  • 左パネルには現在のモードの操作があります。
  • 2Dでは、調整、ディザ除去、減色、独自パレット、検出した画像の色が表示されます。
  • 3Dでは、印刷設定、手動操作、自動ペイントの操作、印刷手順が表示されます。
  • メインプレビューには2D画像のキャンバスまたは3Dモデルが表示されます。

ヒント：3D設定を変更してもモデルは自動で再作成されません。印刷設定、手動の色ごとの厚み、自動ペイントのオプションを変更した後は、3Dモデルを作成をクリックしてください。

最初に適したプロジェクト

主題が明確で背景の細部が少ない、高コントラストの画像から始めてください。4〜16色に減色し、層の順番がわかっていれば手動モード、フィラメントの遮蔽距離を校正済みなら自動ペイントを使います。
