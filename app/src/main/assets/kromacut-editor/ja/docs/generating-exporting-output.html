モデル生成と書き出し

書き出しの手順は、2D画像と3Dの設定が整ってから始まります。

書き出す前に

次の項目を確認します。

  1. 2Dモードで画像を実用的な色数に減色します。
  2. 3D印刷設定のピクセルサイズ（XY）で物理寸法を選びます。層の高さと初層の高さをスライサーに合わせ、自動ペイントの印刷可能な細部の確認と高さディザのために実効線幅を予定押出幅に合わせます。
  3. 手動または自動ペイントを選びます。
  4. 3Dモデルを作成をクリックします。
  5. モデルと層プレビューを確認します。

Kromacutにパフォーマンス警告が表示された場合、画像サイズ、ピクセル数、層数などの負荷により作成が遅くなる可能性があります。それでも作成で続行するか、キャンセルして作業を簡略化できます。

3Dモデルを作成

現在の3D設定をプレビューと書き出し形状に反映させたいときは、3Dモデルを作成をクリックします。

作成中は、画像の色層の読み取り、画像色の割り当て、色層の作成などの進捗が表示されます。進捗表示が消え、更新したモデルを確認できるようになると、書き出し操作を再び使えます。

自動ペイントで新しい積層を計算することと、新しいメッシュを作成することは別です。書き出しは最後に作成したモデルを使い、印刷手順もその作成結果に結び付きます。画像の編集、プロファイルの変更、校正の保存、印刷設定の変更後は、現在の計算が終わるのを待ち、再作成してから書き出してください。新しい設定を計算中、または拒否した後も以前のプレビューが見える場合があります。その表示は、新しい設定が成功した証拠ではありません。

STLか3MFを選ぶ

3Dダウンロードメニューを開き、次から選びます。

形式適した用途
STL幅広く対応する単一形状モデルを使い、フィラメント交換を手動で設定する場合。
3MF複数の色付きオブジェクトを保持できるスライサー向けに、色情報付きの出力が欲しい場合。

3MF書き出しは、自動ペイントで可能な限り物理フィラメント色を保持します。それでも印刷前にスライサーの割り当てを確認してください。

自動ペイントのプレビューでは、少数の実物スプールから数十の混色が見えることがあります。3MFは予測混色ごとに材料を作るのではなく、物理層に実物のフィラメントを割り当てます。そのため、スライサーの通常のフィラメント色表示がKromacutのシミュレーション表示と違っても、材料割り当てが誤っているとは限りません。割り当ての確認には物理色と比較してください。

STLにはフィラメント色や自動スプール割り当てが含まれません。コピーした交換計画を、スライサーの色変更操作とともに使います。3MFもモデルであり、そのまま実行できるGコードではありません。自分のプリンター、ノズル、フィラメントプロファイル、温度、速度を選んでスライスしてください。

フラット印刷モデルでは3MFのみダウンロードできます。物理フィラメントごとに1つのオブジェクトがあり、既定の裏向き配置には透明キャリアのオブジェクトもあります。任意の表向き配置ではキャリアを省きます。どちらの平板も、無色の単一形状STLでは意味を失います。どちらの向きでも滑らかなメッシュのすべての強度を使用できます。強度を変更したらモデルを再作成して、プレビューとエクスポートする形状に反映してください。

印刷手順

印刷手順パネルには次が表示されます。

  • 推奨の外周数、充填率、層の高さ、初層の高さ。
  • 開始色。
  • 層番号と概算高さを示す色交換計画。
  • 計画全体をプレーンテキストで取得するコピーボタン。

コピーした計画をスライサーのプレビューと並べて使います。層番号は層の高さと初層の高さに依存するため、これらの値を一致させてください。

N層目で交換は、新しいフィラメントでN層目を印刷するという意味です。たとえば初層0.10 mm、通常層0.04 mmなら、1、2、3層目の上面は0.10、0.14、0.18 mmです。4層目から次のフィラメントにするには、3層目の後、4層目を押し出す前に交換します。その新しい層の上面は0.22 mmです。

計画の概算高さには注意が必要です。手動方式では新しい層の上面Zを、自動ペイントでは材料交換の境界を示します。似たZ値だけで判断せず、層番号を使い、実際にスライスされた材料の切り替わりを確認してください。スライサーによって、選択層と挿入点のラベルが異なる場合があります。

フラット印刷モードには手動交換計画がありません。代わりに選択した多材料方式の概要が表示されます。各3MFオブジェクトにフィラメントを割り当て、既定の裏向き印刷なら透明フィラメントを使って完成品を裏返すか、キャリアなしの配置を表向きで印刷します。どちらもスライサーで左右反転しないでください。

推奨スライサー設定

Kromacutは次を推奨します。

  • 外周数：1
  • 充填率：100%
  • 層の高さ：印刷手順に表示された値
  • 初層の高さ：印刷手順に表示された値

印刷前には必ずスライサーのプレビューを確認してください。高さは概算であり、初層設定によってスライサーの層変更表示が異なる場合があります。

書き出しはZ縮尺100%に保ち、モデルと一致する一定の層の高さを使います。Z縮尺を変えたり可変層高を有効にしたりすると、物理的な遷移位置が動き、コピーした計画は無効になります。別の層の高さが必要ならKromacutで設定して再作成してください。XY縮尺を変えるとノズルに対する印刷可能な細部も変わります。線幅確認が正しい寸法を使うよう、Kromacutで意図したサイズを設定してください。

スライサーで小さな孤立領域、文字、透明な切り抜きによって分離した部品、土台、パージ/プライムの配置を確認します。輪郭を滑らかにしても、すべての細線が印刷可能になるわけではありません。このアプリはプリンターの流量、リトラクション、温度、機械設定を校正しません。

保存とキャンセル

デスクトップのファイル書き出しは名前を付けて保存ダイアログを開きます。ブラウザーではダウンロード設定を使うため、保存場所の確認が出るかどうかはブラウザーによります。ファイルダイアログをキャンセルしてもプリンターには何も送信されません。書き出し中の形状の書き込みや圧縮には時間がかかることがあります。保存が終わるまでアプリを閉じないでください。

書き出しのヒント

  • 3D設定を変えたらモデルを作成します。
  • 表示上の層プレビュー範囲だけに頼らないでください。書き出しにはモデル全体が含まれます。
  • メッシュが重すぎて作成やスライスが難しい場合は、2Dで元画像を切り抜くか縮小し、不要な色領域を減らします。ピクセルサイズ（XY）を大きくしても同じピクセルが拡大するだけで、数もメッシュの複雑さも減りません。
  • 色数が多すぎて交換手順が無効な場合は、減色に戻ります。
