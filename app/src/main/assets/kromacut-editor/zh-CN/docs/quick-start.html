快速入门

本指南带您完成从加载图像到导出的典型项目。

加载或导入图像

使用预览工具栏中的上传按钮，或将图像拖入2D预览。

加载后，使用鼠标滚轮缩放，拖动预览以平移。如果图像有透明部分，棋盘格按钮可让透明区域更容易辨认。

调整图像

在2D中，先使用调整，再减少颜色。曝光、对比度、高光、阴影、白色色阶、黑色色阶、饱和度、自然饱和度、色相、色温、色调及清晰度都会改变调色板工具找到的颜色。

减少颜色、构建3D几何体或下载前，请点击调整面板中的应用，将当前调整写入图像。仅实时调整只是预览，不会更新源图像。前后对比及重置行为请参阅图像调整。

按需调整尺寸

如果图像远大于希望打印的细节尺度，请在减少颜色前用调整图像尺寸按百分比缩小。这会减少实际像素尺寸，让后续3D模型构建更快，也更容易设定实体大小。

减少颜色

在量化设置中：

  1. 除非已确定要用某个调色板，否则让调色板保持自动。
  2. 从颜色数量设为16开始。降低数值可减少源颜色区域；预览需要更多细节时可提高。在自动配色中，这个数量不是耗材卷数或换料次数。
  3. 算法保持默认的K均值。它是多数图像推荐的起始算法。
  4. 点击应用。

使用图像颜色面板检查结果。点击色样可编辑它或从调色板中删除。删除会将像素重映射至剩余颜色；如要从轮廓移除像素，请使用橡皮擦，或把Alpha设为零（完全透明）。

去抖动或清理

如果减色后留下孤立杂点，可使用去抖动进行降噪。2D图像中单个零散像素可能变成3D模型中单独的几何碎片，因此此操作尤其有用。

先使用默认的权重和遍数，点击应用。只有一遍处理后仍有过多孤立像素时，才增加遍数。

启用3D模式

点击3D，先设置基本打印参数：

  • 像素尺寸（XY）控制每个图像像素的实体宽度和深度。
  • 层高应与计划使用的切片层高一致。
  • 首层高度应与切片软件的首层设置一致。
  • 平滑网格可平滑相连的颜色边界，使几何体更圆滑。

选择手动或自动配色

想直接控制减少后的图像颜色时，使用手动。手动模式使用图像颜色中的色样：拖动颜色设置打印顺序，再用每行滑块决定该颜色贡献多少高度。如果已知道所需层顺序，或要匹配小型简单调色板，这是很好的起点。

想让Kromacut规划实体耗材叠层时，使用自动配色。自动配色从实际耗材出发，而不是从减色后的图像色样出发，再利用各耗材的颜色及遮盖距离（HD）——遮住下方材料所需的深度——估计叠层外观。

首次自动配色建议：

  1. 添加实际计划使用的耗材。
  2. 尽可能准确地设置每种耗材的颜色。
  3. 设置每种耗材的HD。魔棒估算适合试验，也可转换传统TD值（约为HD的10倍）；校准后的遮盖距离通常效果最好。
  4. 初次让最大高度保持自动。
  5. 如果首次结果缺少重要颜色，或希望优化器搜索更佳耗材顺序，可启用增强颜色匹配。

自动配色计算叠层后，导出前请检查过渡区域和置信度详情。置信度低通常意味着耗材组合缺少有用颜色、遮盖距离需要校准，或最大高度限制过严。

生成并导出

点击构建3D模型。模型出现后，用层预览滑块检查打印如何由下向上构建。

打开下载菜单，选择下载STL或下载3MF。然后复制打印说明，保留起始颜色、换料层及推荐切片设置。
