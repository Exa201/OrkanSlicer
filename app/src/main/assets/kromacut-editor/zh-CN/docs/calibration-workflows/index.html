校准流程

校准帮助自动配色预测耗材叠层外观。它不是打印机校准：这些工具不调整挤出、温度、热床调平或喷嘴设置。请先使用可靠的切片设置，再按作品计划采用的相同材料及观察条件测量。

打开3D → 自动配色 → 校准。对话框包含遮盖距离、配色校样和叠层校准矩阵。它们测量不同内容，也可结合使用。

工具适用情况您提供的内容后续可能改变的内容
遮盖距离耗材不透明度未知或仅为估计首个与参考条匹配的楔块色块HD、通道估计、过渡厚度、总高度及换料计划
配色校样最重视一张图案中的少量颜色最接近的打印候选及匹配质量局部颜色预测和叠层偏好，可能影响顺序、高度和几何体
叠层校准矩阵希望测量许多短配方的颜色正确对齐的正面照明照片测量配方预测、局部插值及经过验证的实体拟合

这些工具都不会提高打印机XY分辨率，也不会让所有目标色都可实现。充分校准的配置仍可能色域有限。底层模型请参阅校准理论。

准备并保护耗材配置

耗材行描述实际耗材卷，不是希望得到的图像颜色。

名称为耗材卷提供可读标签改名不改变光学性质。跟踪校样或矩阵前请保存编辑。

记录外观证据前，使用配置工具栏保留命名且未更改的组合：

  • 配置下拉框：将已保存组合加载到工作耗材。加载另一组合会替换当前列表，因此请先保存需要保留的编辑。
  • 保存选中配置：用工作值覆盖耗材列表。已有校样和矩阵记录保留，但不兼容记录不再适用于更改后的组合。
  • 另存为新配置：创建单独命名的耗材组合。复制耗材行及楔块测量，不复制旧配置的校样和矩阵历史。
  • 重命名：改变配置标签，不改变测量。
  • 导入：加载耗材文件。导出将干净命名配置连同校样评价和矩阵测量备份为.kfil。桌面导出打开另存为；Web导出遵循浏览器下载行为。
  • 删除选中配置：移除已保存配置及其证据。以后可能需要时，请先导出备份。

未保存更改标记表示工作组合不同于选中配置。创建矩阵或记录校样结果前，请保存或覆盖。带未保存编辑时导出会创建不含旧外观历史的“未保存编辑”配置，不是该历史的完整备份。模板是带估计HD的只读起始组合，因此校准前请保存自己的副本。参阅配置文件格式与导入处理。

遮盖距离：读取楔块

1. 选择耗材与底色

选择一种或多种耗材，或用全选 / 全部取消，再选择下一步：底色。

  • 快速每种耗材使用一种底色。它测量标量不透明度阈值，并保留从色样估计的保守通道差异。
  • 准确允许每种耗材选择最多三种底色；可用时初始推荐两种有用底色。每种底色产生独立楔块读数。这改进受约束的通道估计，不独立测量三个光谱通道。
  • 底色色样选择该耗材下方打印的材料。使用有对比的底色，让薄色块能明显不同于参考条。几乎相同的底色和耗材无法提供有效不透明度阈值。

切换快速/准确会将底色选择重置为该模式建议。准确模式适用于能在多种基材上比较同一材料的情况，而不是因为名称承诺始终更好。

2. 设置并打印楔块

控制对校准打印的影响
层高（mm）设置每个附加楔块层的厚度，范围0.04–0.40 mm。更细层高提供更细测量步长，但不会使不支持的打印设置变可靠。
最大层数（楔块长度）选择4–40步。更多步扩展透光耗材的测量范围，并使楔块更长、更高。
STL（任意打印机）下载一块无色试片。为每个所选耗材/底色组合打印一份，使用列出的手动换料。
3MF（多材料）在一个文件中包含所有所选读数及实际耗材/底色分配。请验证切片材料映射。
下载导出当前楔块计划。结果步骤使用该计划层高及底色选择，不使用后续无关编辑。

请严格使用显示的常规层高、首层高度及第几层后 / Z处换料。首层高度来自打印设置；楔块自身层高控制与普通3D模型设置分开。不要沿Z缩放。下一步：输入结果打开读数步骤；下载不会向打印机发送任何内容。

桌面上两种楔块格式均打开另存为；浏览器使用普通下载行为。修改设置或输入结果前，请等待导出完成。取消另存为或导出失败会保持上次成功下载的楔块计划不变；保存失败时显示错误以便重试。

3. 比较并保存

将打印楔块正面朝上，在预期正面光下观察。凸片标记单层端。将各色块与旁边参考条比较，而不是与手机照片或屏幕色样比较。

  • 匹配：输入首个看起来与参考条完全相同的色块编号。这是色块增加的耗材层数，不是打印机绝对层号。
  • 合并（可选）：输入最后一个仍与前一个色块不同的色块。它检查拟合曲线，不是第二个必需不透明度测量。合并值晚于匹配值时会警告。
  • 预测色样 / HD / 置信度 / 诊断：显示从读数推断的结果。这是反馈，不是需要额外提供的测量。
  • 保存校准：应用完整、可用的耗材测量。空白耗材为未输入，保持不变。准确模式下只填部分的耗材显示不会保存，直到每种所选底色都有匹配值。无需完成整张试片，也可保存其他完整耗材。

最后一块仍不同于参考条时，不要为完成任务而谎称匹配；请打印更长楔块。第一块已经匹配时，更细且可打印的层高或更有对比的底色可使测量更有信息。可用范围端点的读数置信度较低。

重新校准会替换该耗材此前的楔块结果。要组合多种底色，请在同一准确会话中一起读取。之后保存/覆盖命名配置并导出备份。测量HD同时改变预测颜色及自动配色认为必要的材料量；请重新构建，检查新高度与换料说明。

返回可重访向导步骤。关闭对话框会重置未保存的楔块选择及读数，因此离开前请保存可用结果。多个完整多底色读数触发会话拟合时，请等完成后再保存；等待的计算不是需要输入的新测量。

配色校样：比较图案颜色

校样从当前自动配色叠层打印多个候选。前缀表示基础层及其上直到某停止高度的每一层。校样比较可打印停止高度，不是耗材卷的任意独立混合。

选择目标和候选

先让自动配色完成计算，得到至少两个合格可打印前缀。不必先构建图案3D网格。保存其命名耗材配置，再打开配色校样。

控制含义
目标比较的图案颜色数，最多10或可用数量。颜色足够时默认8。
候选每个目标请求的替代数，通常2–5，受可用有效前缀限制。更多候选使试样更宽。
从图像选择打开独立目标选择视图。点击重要图像区域或其颜色开关。
原始图像以外观拟合前的处理后图像颜色为目标，不是未修改的上传照片。
拟合 / 可实现以当前自动配色结果使用的确切预测颜色为目标。可检查打印是否匹配预览；“可实现”不认证实体准确度。
校样目标总数在图像选择过程中设置同一目标数量。
清除选择移除手动优先项，让空位恢复智能选择。
使用智能目标 / 使用所选＋智能带优先项返回校样，自动填充剩余位置。

选中颜色在图像所有出现位置保持明亮，未选区域变暗。选目标不会重着色源图，也不会强制其进入打印机色域。减少目标数可能丢弃超出数量的优先项。

打印并识别试样

校样图和结果视图每行一个目标，候选A–E由左至右。数字标识目标行。F表示共用基础层参考，不是第六候选色或另一耗材。请与裸露基础层边缘比较。

下载3MF导出试样，并为干净命名配置保存身份及配方图。保存后锁定目标选择和数量，避免结果悄悄指向另一打印。保持正面朝上、100%比例，使用嵌入的常规和首层高度，验证耗材分配，以缺失的左上角定位。默认8目标×5候选试样为44×68 mm。8 mm色块在连续基础层上相接，因此边界可能不如屏幕网格明显。

打开结果，在一致观察条件下将打印候选与显示目标比较，选择最接近的色块。并列时选择多个，再描述匹配程度：

  • 继续目标：用当前兼容叠层为相同目标打印下一轮。保留选中的先前最佳，测试附近未尝试挑战者，并可包含一个探索叠层。均不合适没有先前最佳锚点，因此下一轮探索替代。

  • 候选较少 / 目标已穷尽：搜索不会仅为满足请求尺寸，用无关重复填满板。请阅读警告；有效选项较少不代表校准丢失。
  • 删除校样：确认后，从外观证据移除该保存试样及其所有评价。

没有原图也可阅读保存结果。再次下载保存校样需要其确切源自动配色快照；继续目标需要兼容的当前图案/工艺。以后可能重印时，请保留原始3MF。

校样评价可改变附近预测色、叠层排名，最终也可能改变打印高度。它不会改变导出层实际分配材料，也不覆盖耗材HD校准。单次结果不能建立全局准确调色板。更广拟合受证据和留出验证门槛约束；即使拟合未活动，局部评价仍可有用。

叠层校准矩阵：拍摄已知配方

规划校准板

请先保存一个未再修改的命名配置。在选择新建矩阵之前，在3D打印设置中设定所需的层高和首层高度。遮盖距离楔块的层高字段不控制矩阵。

控件对校准板的影响
耗材色样按配置顺序选择2–8种耗材。只有这些材料会用于配方层。
最大颜色厚度（mm）限制单层基础上方的颜色区域厚度。向下取整为完整的常规打印层，范围为1至64层。层高为0.04 mm时，0.40 mm的上限允许最多10层的配方。
最大单元数限制配方数量：64、144、256、400、625、1,024、1,296、1,600或2,025。较大的校准板能采样更多配方，但会占用更多打印平台面积和打印时间。
计划材料更换预算限制规划器估算的材料更换次数，包括角部参考标记。可选择40–640次更换或规划器不设上限。这不是耗时估计，也不保证切片软件最终的换料次数。
衬底耗材从已选耗材中选择一种，用于单层基础和较短配方下的填充。默认使用已选耗材中最浅的一种。较薄的首层不保证不透明。
层高 / 首层高度以只读方式确认新校准板将使用的当前3D设置。
配方 / 尺寸 / 高度 / 换料摘要下载前显示占地尺寸、基础＋颜色区域高度、总高度和打印层数。已保存校准板显示其固定高度、选定单元、计划更换次数、参考单元以及规划时考虑的历史板。
创建并下载3MF规划配方、导出校准板，然后将保存的计划记录在配置中。

新校准板采用自适应覆盖：通过有界、可重复的搜索，在允许的厚度范围内对配方采样。它优先填补先前已测颜色的空缺，测试尚未测试的深度和耗材过渡，并探索预测依据不足或先前预测与测量不一致的配方。预测出的新颖性不保证打印出的颜色一定是新颜色。少量参考单元会有意重复，以便比较连续拍摄的照片。

只有已完成且配置/材料数据、衬底、打印高度兼容，并已接受照片对齐的校准板，才会指导下一块板的规划。下载尚未打印的计划不等于其颜色已被测量。请保留已完成的校准板：选择新建矩阵时会自动考虑符合条件的测量。更换衬底或打印设置可能开启一个独立的覆盖范围上下文。

新校准板使用由首层高度决定的单层基础，不会再添加根据不透明度确定厚度的底板。例如，0.10 mm首层＋0.40 mm颜色区域＝0.50 mm总高度。使用0.04 mm常规层高时，共有11个打印层：一个基础层和十个颜色区域层。高度摘要会在下载前显示这一分解；查看旧校准板时，则使用实际保存的基础数据。

所有色块的顶部仍处于同一平面。较短的配方会在颜色层下方垫上同一种衬底耗材的额外层，这些层位于颜色厚度上限之内。这种填充不会增加所显示的总高度。保存的记录会同时保留有效配方及其衬底填充。

较薄的首层并不会自动变得不透明。请选择不透明的衬底耗材，并将校准板放在一致、平整的衬垫表面上拍摄；从下方透出的光线或颜色会影响测量颜色。只有额外衬底确实遮住下方物体时，才能将其视为光学上中性的部分。

在仍然半透明的基础上进行的测量会保留其实际衬底厚度。它们可以支持匹配的物理叠层，但不能在不同衬底厚度之间作为可互换的测量，也不能用于拟合全局不透明衬底模型。即使裸露的首层不透明度不足，填充仍可能使部分色块变得不透明。

新校准板会将相似配方放在一起，使同色区域更连续并减少碎片化的工具路径。分组本身并不会减少每个打印层所用的耗材种类，因此不保证减少材料更换次数或节省特定时长。现有已保存校准板保留原始单元位置，确保其照片仍能匹配。

厚度上限不会强制每个配方使用那么多颜色层。单元数和材料更换预算可能使实际单元数少于请求数量，而紧张的换料预算可能使部分已选耗材未被使用；出现这种情况时，保存的计划会给出警告。如果连参考色块都超出换料预算，请增加预算，或降低厚度上限、减少所选耗材。即使单元很少，较深的校准板和CFS/AMS冲洗仍可能很耗时：打印前请检查切片软件的最终估计。

保存的摘要会统计所选配方中尚未在兼容历史板上测量过的数量。如果该数量为零，则计划只是在重复现有测量；可以跳过打印，并尝试不同限制或材料。这并不证明所有可实现的颜色都已测量，因为搜索范围是有限的。

单元尺寸固定为5 mm、没有间隙，外加标记边框；例如，32 × 32的数据网格会占用170 × 170 mm的校准板。较早保存的校准板保留固定配方深度以及全部组合或HD选定色域标签；重新下载不会将它们转换成自适应格式。

在桌面版中，取消“另存为”不会创建新的保存计划。在浏览器中，下载开始时就会记录计划。请留意存储错误信息，并保留3MF文件。保存的校准板会固定其层高、衬底和配方布局：后续设置变化不会重新设计它，在该记录上选择下载3MF会再次导出原始校准板。

以100%比例、正面朝上打印，并使用完全一致的层高和耗材分配。低于常规层高的首层高度会调整为常规层高。基础仍是在这个有效首层高度下的单层，不会为了达到不透明度目标而加厚。较早保存的校准板保留原始基础，包括任何额外基础层。这是实物校准工具，因此更改Z轴比例或材料映射会使单元原本要测量的内容失效。

决定采样方式，然后保存

参考标记校正默认关闭。关闭时保留照片采样颜色，包括相机偏色。开启后，会比较照片中的四个标记与其预测配方颜色，估算并应用各通道增益。它可以减少整体偏色或亮度偏差，但并不独立测量室内照明，也不能修复阴影或眩光。标记预测不正确同样会使结果产生偏差。预览更亮并不证明测量更准确。

提取的查找表预览显示将要保存的颜色，每个配方对应一个色样。将鼠标悬停在单元上可查看采样RGB值。请将其与实物校准板及预期观看条件比较，而不是期待每个单元都应该鲜艳。

样本和对齐检查准备就绪后，即可使用保存校准。对于已完成的记录，按钮显示为替换校准，会替换该记录的照片测量；若想保留两个版本，请先下载/导出备份。保存的配置包含颜色和配方数据，以及照片元数据，但不包含原始照片。如果以后可能需要重新采样，请单独保留源照片。

理解置信度，不夸大准确性

耗材徽章、结果置信度以及外观模型 / 预测置信度描述的是不同事物：

  • 耗材置信度关注楔块测量受到多大程度的约束。范围边缘的读数、结果不一致或数据老化会降低它。“估计”表示没有活动的楔块测量。
  • 结果置信度综合校准、覆盖率和压缩情况。即使综合分数较高，配方颜色也可能完全来自模拟。
  • 外观模型标明可用的实测证据和拟合状态。已比较叠层、锚点、局部邻域及矩阵查找表配方的数量，说明本次运行实际参考了哪些内容。
  • 预测置信度描述映射到这张图像的颜色获得了怎样的支持，包括测量、插值、拟合或模拟预测。测量配方仍然只是特定条件下相机或人的观察，并不是实验室保证。

选择最不差的校样色块时，请使用现有最佳，而不是“完全一致”。不要不断调整矩阵照片，只为让预览看起来好看。真正有用的下一步，是进行小型实物测试，检查实际更改的颜色和打印设置。
