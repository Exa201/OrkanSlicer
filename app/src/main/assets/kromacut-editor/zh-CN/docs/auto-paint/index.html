自动配色控制

自动配色预测薄耗材层相互叠加的效果，为准备好的图像选择可打印高度。同一种实体耗材的不同厚度可产生多种可见颜色，因此二十种图像颜色不一定需要二十卷耗材。

设置实体尺寸、层高及有效线宽，添加实际可装载的耗材，等待计算，再构建3D模型。输入改变会自动重新计算；显示几何体仅在构建时更新。

模板

供应商模板提供宣传颜色、名称、品牌和估计HD，只读。移除未拥有的颜色，校准后另存为新配置。供应商参考颜色不保证具体批次或观察环境。模板是非官方的，不代表供应商认可。

标准匹配

关闭增强颜色匹配时，Kromacut按亮度将耗材从暗到亮排序并计算过渡，不遵循行添加顺序。图像到高度的映射也使用亮度：在最暗和最亮的非透明图像像素间归一化亮度，将该范围放在基础层表面和叠层顶部之间，再吸附至可打印层。因此，两个不同色相但亮度相同的颜色可能得到相同高度，与色相无关。重复、颜色分离、高度抖动及优化器控制不启用。

这种较简单基线适合以亮度为主的浮雕。增强匹配在选择材料顺序和可打印颜色分配时都考虑图像颜色，因此色相差异重要时应使用增强模式。

最大高度

清空最大高度或按自动，可使用计算得到、与层对齐的叠层高度。范围为0.5至20 mm。上限是天花板而非目标，因此结果可能更低。

处于有效层边界之间的上限向下取整。常规过渡过高时，Kromacut会压缩它们，并显示自动高度供比较。

示意图。彩带标识材料连续段，不代表预测混色外观。

基础层仍必须在每个建模RGB通道达到约95%不透明度。上限不足会拒绝叠层，而非将透光衬底当成不透明。请提高上限，或使用HD更短、能充当基础层的耗材。

压缩可能移除有用中间色，它不是对相同图像进行均匀缩放。平面打印模式中，透明承载层是额外几何体，首层布局也不同于浮雕。请检查完整模型尺寸和切片厚度；最大高度不是含承载层的总板厚。

可打印细节

将3D打印设置中的有效线宽设为切片软件的预期挤出宽度，而非喷嘴直径或像素尺寸。自动配色宽度警告预览和可选孤立色点清理使用同一设置，控制项仍在这里。

设想蓝色背景上的两像素紫色条纹。在0.10 mm/像素下，条纹宽0.20 mm。计划挤出线若宽0.40 mm，条纹就比线窄。Kromacut可将其标为有风险，但即使开启清理也保留条纹。细窄可见区域可能属于下方更宽的材料层；切片路径可能保留此仅基于图像检查所标记的细节。

这是宽度估计，不是确切切片路径。色条比较宽度，方形图展示示例图像。

略去孤立色点提供两种选择：

  • 关闭：自动配色输入保留全部源像素，包括每个高亮区域。
  • 开启：匹配及模型生成前，仅将专用于微小、紧凑、封闭色点的颜色替换为周围更宽的颜色。色点整体尺寸必须小于有效线宽，并有唯一明确且区域更宽的周围颜色。若该源颜色还用于图像任意位置的线条或更大区域，则各处均保留。

细线、对角连接、附着于较宽区域的分支、图像边缘细节，以及透明或多色旁的色点都会保留。清理绝不将像素变成孔洞，也不编辑原始2D图像。它有意保持谨慎，可能留下不需要的杂点；更广泛编辑请用2D清理。

使用打开预览检查：

  • 有风险：琥珀色标记靠近更宽颜色的细源色区域；粉色标记没有更宽邻居的细区域。其他像素变暗。这些是警告，不是细节无法打印的预测。
  • 结果：可选清理后自动配色收到的像素。它不是切片预览，也不保证可打印。
  • 标记 / 符合条件 / 略去：宽度警告比例、满足孤立色点规则的像素及实际替换数量。保留的标记像素明确统计不改变图像的警告。

符合条件的色点颜色被略去时，自动配色使用清理图像统计目标色并规划叠层。移除整个目标色可能改变其他位置的匹配，因此请检查重新构建结果。警告百分比非零但略去0像素，表示清理保留了全部源细节。

改变开关后，请等自动配色计算完成，再次点击构建3D模型。分析测量的是连通源颜色区域，不是实体材料层、墙、填充或可变宽度挤出。务必检查切片路径。如果细节确实在那里丢失，请增大模型XY尺寸、在2D中加宽，或选择打印机和切片软件支持的更细挤出宽度。

增强颜色匹配

增强匹配为当前2D调色板搜索材料顺序，可省略没有增加有效覆盖的耗材。八卷可用耗材不一定产生八个连续段。

优化器不会暗中再次减少准备好的调色板。源颜色越多，工作量越大。先按减少颜色准备图像，再在3D中判断可实现外观。

关闭增强匹配也会关闭颜色分离和高度抖动。新计算取消旧计算；进度为近似值。失败计算不能回退到无关手动叠层。在构建有效新结果前，旧的已构建模型可能仍可见。

总重复限制

为整个叠层选择关闭，或最多2、4、6、8、12次额外出现。这既不是每种耗材的额度，也不是确切换料数。黑 → 黄 → 黑使用黑色的一次额外出现。在新衬底上再次使用材料，会创建另一条混色路径。

概念顺序及分配，并非材料预测。

更多重复允许更广搜索，也可能增加打印时的材料切换。额度是上限，不需要的连续段可省略。

保留颜色分离

普通匹配可能将不同图像颜色映射到同一输出。当区别重要，例如文字与背景或相邻面部色调时，启用保留颜色分离。

唯一匹配限制（ΔE）是某图像颜色拥有独立可打印输出所允许的严格最大色差。范围1至100，默认6。较低值要求更近的匹配，更难满足。较高值允许更多误差，不会改善实体耗材。

要求每种颜色都有唯一匹配默认启用，不完整分配会失败。关闭可使用部分调色板：未匹配颜色失去独立输出，合并到保留映射中。图像仍填满，但失去区别。若没有任何颜色符合条件，即使部分模式也失败，因为没有合并目标。

优化器先最大化保留颜色及源图覆盖，再优先减少重复出现、材料连续段和实体层，最后降低限制内误差。重复额度逐步探索，所有颜色保留后可停止搜索。最后的删除检查移除不能改善这些优先目标的单独连续段。

严格失败时，可考虑减少2D颜色、增加高度或重复、添加合适耗材、提高ΔE限制或接受部分合并。请选择实际想要的取舍，不要仅为消除错误而提高限制。

颜色分离和高度抖动互斥。启用任意一项会关闭另一项。

高度抖动

输入含有可用层边界之间的高度时，高度抖动可将舍入误差分布到相邻可打印高度的小块中。从一定距离观察，这些高度差可能呈现中间色调。它需要增强匹配，作用于导出的高度图，而非2D源图。

机制示意，不保证前后结果。不同顶面高度不代表增加耗材卷颜色。

启用抖动后，如果所选层与相邻可打印层的混合能改善预测的颜色匹配，自动配色就会在两者之间寻找中间高度。精确颜色匹配和已校准目标的匹配保持所选高度；没有合适相邻混合的区域也保持不变。更改设置后请重新构建模型，再比较预览与切片结果。关闭抖动会恢复普通的离散层匹配。

点尺寸由3D打印设置的有效线宽相对于像素尺寸决定，并舍入到整像素块尺寸。这是近似值，不是确切最小宽度保证。边缘区域避开相同抖动处理以减少边界伪影。请在切片软件中检查小孤岛及额外移动。

存在小数高度误差时，重新分布可帮助大面积色调，但可能使微小图形有噪声或几何更重。它不能补充缺失色域，也不能验证不支持的校准。产生许多小区域时，与平面打印结合尤其昂贵，因为这些区域共处于每个完整占地层中。

优化器设置

权重和选择为示意，不是测量颜色或确切层数。暗化区域优先级较低，并未从图像移除。

控制选项与效果
算法快速：较窄、较快的搜索。平衡：通用默认值。彻底：更深的多起点改进。深入：更广、更昂贵的搜索。精确基础顺序：枚举适用的无重复顺序。
区域优先级均匀：像素等权。中心加权：偏重中央附近颜色。边缘加权：偏重图像边缘颜色。改变匹配优先级，不改变裁剪或挤出。
过渡细节紧凑（80%）、详细（90%，默认）、最大（95%）设置过渡不透明度终点。较高值允许更高过渡及更多可打印中间色，但受提前收敛和高度上限限制。
种子（可选）自动使用由输入导出的稳定种子。输入整数可比较另一确定性搜索；清空恢复自动。它不是质量滑块。

过渡细节影响上方材料过渡，不改变不透明基础层要求。它不提高图像分辨率，也不缩窄线宽。额外过渡色可能对当前图像无用。

相同种子下，更高启发式级别保留下一级的最佳结果，但仍只是优化预测。精确基础顺序在八种耗材时检查109,600个非空顺序，九种时986,409个。重复使用独立改进流程，不穷尽证明所有重复叠层。

过渡区域与置信度

读数解释
过渡区域带起点、终点及厚度的实体材料连续段。压缩标记表示厚度低于理想值。
总高度 / 实体层数计算得到的叠层尺寸，不是图像颜色或耗材卷数量。
颜色分离状态保留和合并颜色、可打印容量、保留色最差ΔE及重复。合并目标不是成功的超限匹配。
外观模型预测由模拟、拟合行为、局部比较还是矩阵证据支持。测量计数不代表每个输出都经测量。
预测置信度：平均 / 最低实际映射颜色的证据强度。加权平均可能隐藏最低值揭示的薄弱区域。计数区分测量、插值、拟合预测及模拟。
结果置信度综合HD校准、覆盖及压缩指标。不是测得准确度百分比，也不同于预测置信度。
校准 / 覆盖 / 压缩HD证据质量、耗材对源颜色的覆盖及高度上限影响。高分不认证打印。
质量分数优化器比较，不是测量。非严格颜色分离不完整时，标签变为部分调色板。
迭代 / 缓存命中搜索工作量及结果复用。更多迭代不证明颜色更好。
精确最优 / 已找到最佳适用无重复顺序的穷举比较，与启发式或重复叠层改进的区别。均不证明实体准确度。
无可移除连续段删除任一连续段均无法保持所选优先目标。另一多段重排可能仍更好。

远离测量、附近观察互相矛盾，或留出预测未命中测量色时，证据减弱。普通匹配可包含有限的不确定性成本。颜色分离仍以原始ΔE判断资格，因此不确定性不能让超限颜色变有效。

改变工艺或层高后，请检查此证据摘要。较高总体校准分不代表每个新配方都受支持。参阅校准流程。
