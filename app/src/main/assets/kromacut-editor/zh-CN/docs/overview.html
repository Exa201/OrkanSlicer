概述

Kromacut将平面图像变成颜色分层叠加的3D打印作品。核心思路很简单：图像中的颜色变为实体层，而这些层的顺序和高度成为打印计划。

如果您想制作HueForge风格的打印作品、彩色光刻浮雕风格的作品，或通过换料形成最终图像的分层展示品，可以使用Kromacut。

主要工作流程

多数项目遵循相同路径：

  1. 加载或导入图像。
  2. 减少颜色，直到预览具有可打印的调色板。
  3. 如果图像有噪点，对孤立像素进行去抖动或清理。
  4. 切换到3D模式，选择手动或自动配色。
  5. 构建并导出STL或3MF文件，按打印说明操作。

两种配色方式

Kromacut在3D模式中提供两种打印流程。

流程适用情况可控制内容
手动希望直接控制每一种图像颜色。颜色顺序、每种颜色的层段厚度、打印设置和换料。
自动配色希望由Kromacut规划实体耗材叠层。耗材颜色、遮盖距离值、最大高度及优化器选项。

手动模式从图像颜色面板中的颜色开始。自动配色从实际耗材及其遮盖距离（HD）开始，为图像生成可打印层。

工作区布局

工作区有三个主要区域：

  • 顶部包含文档、主题控制和社区链接。
  • 左侧面板包含当前模式的控制项。
  • 2D中显示调整、去抖动、量化、自定义调色板及检测到的图像颜色。
  • 3D中显示打印设置、手动控制、自动配色控制和打印说明。
  • 主预览显示2D图像画布或3D模型。

提示：3D设置不会自动重新构建模型。更改打印设置、手动层段厚度或自动配色选项后，请点击构建3D模型。

适合首次尝试的项目

先选一张对比度高、主体清楚且背景细节有限的图像。将其减少到4至16色。若已知道所需层顺序，可使用手动模式；若已校准耗材遮盖距离，则使用自动配色。
